# AI Prompt Screenshots

AI-assisted development (Claude) was used while building and reviewing this project, as explicitly welcomed by the assignment brief.

The assignment asks for screenshots of the **actual prompts used**, taken directly from the chat/IDE panel, so the reviewer can see exactly what was asked. This folder is intentionally prepared for that — **no screenshots have been generated or faked here**. The real screenshots must be added manually before submission.

## What to add

Take real screenshots of the actual Claude conversation(s) used during development and review, and save them here as image files (`.png` or `.jpg`).

Suggested naming, matching the phases the review actually went through:

```text
prompts/
├── 01-project-review.png        (initial full project audit against the assignment PDF)
├── 02-database-review.png       (schema / migrations / relationships review)
├── 03-api-review.png            (endpoint behavior verification)
├── 04-concurrency-review.png    (lockForUpdate / transaction review and live MySQL verification)
├── 05-testing-review.png        (test suite review and additions)
└── 06-final-review.png          (final documentation + GitHub preparation pass)
```

The exact filenames aren't important — what matters is that they are genuine screenshots of the real conversation, not placeholders or recreations.

## What not to do

- Do not create placeholder or mock screenshots.
- Do not claim in any documentation that screenshots exist here if this folder is still empty.
- Do not edit or crop screenshots in a way that misrepresents what was actually asked.
